# 🧱 Primitivas e STL Clássica (Fundamentos) 

> Estruturas nativas do C++. O segredo aqui não é a implementação, mas evitar TLE/RTE por uso incorreto dos métodos e over head de memória.

- [[vector]]: Array dinâmico. Padrão para tudo, compressão de coordenadas e grafos (lista de adjacência).
- [[queue]]: Fila FIFO. Base absoluta para BFS.
- [[deque]]: Fila de ponta dupla. Essencial para Sliding Window e BFS 0-1.
- [[stack]]: Pilha LIFO. Base para DFS iterativa e Monotonic Stack.
- [[priority_queue]]: Heap (Max/Min). Essencial para Dijkstra, Prim e Greedy.
- [[set]]: Árvore Red-Black (BST ordenada). Busca rápida com ordem mantida.
- [[map]]: Mapeamento chave-valor ordenado (BST).
- [[unordered_map]] / [[unordered_set]]: Tabela Hash. Acesso O(1) médio, mas com risco de colisões (Anti-Hash TLE).
